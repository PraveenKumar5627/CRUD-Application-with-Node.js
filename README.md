# CRUD User Management Application

## 📌 Project Description

This project is a CRUD (Create, Read, Update, Delete) User Management Application.

It allows users to add, view, edit, and delete user records through a simple web interface.

The application demonstrates how a frontend communicates with a backend API to perform CRUD operations.

## ✨ Features

- ➕ Create – Add a new user
- 📖 Read – Display all users
- ✏️ Update – Edit existing user information
- 🗑️ Delete – Remove a user
- 📝 User fields include:
  - Full Name
  - Age
  - City
- 🔄 Dynamic data updates
- 🖥️ Simple and user-friendly interface

## 🛠️ Technologies Used

### Frontend

- React.js
- JavaScript
- HTML
- CSS
- Axios

### Backend

- Node.js
- Express.js
- REST API

### Data Storage

- JSON file

## 📂 CRUD Operations

| Operation | Method | Description |
|---|---|---|
| Create | POST | Add a new user |
| Read | GET | Get all users |
| Update | PUT | Update an existing user |
| Delete | DELETE | Delete a user |

## 🔄 Application Flow

User Interface
↓
React.js Frontend
